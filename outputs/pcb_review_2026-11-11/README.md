# Rev E 两板 PCB 独立审查

运行方式：在仓库根目录使用 KiCad 自带 Python 执行 `tools/verify_reve_pcbs.py`。工具只读取已保存 PCB、当前 XML 和两个合同；只在本目录写报告，不保存 PCB 或工程。默认重新运行两板原生 CLI DRC，报告实际违规、未连接和原理图一致性数量；`--skip-drc` 仅用于局部读回，不能作为最终 DRC 结果。

最终检查输入为 `docs/pcb_stack_contract_rev_e.json`、`docs/daughterboard_pin_contract.json` 及两块板各自的 `review/*.net.xml`。原理图共 364 个电气位号、1202 个唯一物理引脚；每板另加 H1–H4 安装孔。MOS 大散热铜面重复 5 号，因此实际铜焊盘数量与唯一物理引脚数量分别记录。

检查内容：

- 电气位号、全部物理 pad、原理图网络及完整网分区、DNP、封装和数值。显式 NC 仍须保留实体 pad，可使用空 PCB 网络；同号重复铜 pad 分别核网。
- 60×60 mm 外框、板厚、4/6 层、四孔同心、2.2 mm NPTH 及孔心半径 2.8 mm 铜净空。未填充铜区会单独列出，不能由空缓存证明净空。
- J101/J102 的 64 个同号 pad 在共同 XY 中逐个同心。公头在核心 TOP，母座在底板 BOTTOM；供电网络按合同别名检查，底板闲置触点按 NC 检查。
- 原生 courtyard 多边形的同面交叠、越板、缺失，以及安装硬件区域和下板按键操作区的障碍。
- MCU、RESET/BOOT 的顶面要求和按键近边位置；全部已关联 3D 模型路径解析。缺模型、通用模型和实际高度不能相互替代。
- 对当前 PCB 重跑的原生 DRC 和 pcbnew 原始未连接数；报告记录输入哈希，并核对审查前后源文件未变。

已核机械基础：PZ254V-12-32P 公塑座名义 40.64×5.0 mm，PM254V-12-32-H85 母塑座 41.14×5.0 mm；38.10 mm 只是首末针中心距。详见共享库 `docs/parts/batch_2026-11-10/README.md`。TS-1101-C-W 按键本体 6.05×3.70 mm、顶高 2.50±0.10 mm，详见共享库 `docs/parts/TS-1101-C-W.md`。

对当前专用母座封装，在内存 BOARD 内放置后执行 `Flip(position, False)`，实际同号 pad 与 0°公头对齐；KiCad 会显示 B.Cu / 180°。应以实际 pad 坐标验收，不能翻面后再次设 0°。本检查不调用翻面或修改接口。

板间支柱长度、插合深度、按键侧面手指/工具可达性仍按共同合同留待装配核验。塑高 2.5+8.5 mm 不能单独作为已验证的支柱规格。本目录的检查结果是设计审查记录。
