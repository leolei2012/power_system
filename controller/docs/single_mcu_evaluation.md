# 单颗 LKS32MC451VCT8 资源初评

2026-11-05：本文为旧分板/集中控制方案的参考记录。当前按 [变频板与电源板各一颗 MCU](../../docs/integrated_board.md)推进，MCU 改为 STM32G431 方向，电源板 PFC＋LLC 恢复评估；本文旧引脚、资源数量和检查不能覆盖新版。


## 最新需求与进度（2026-10-31）

同一块控制板仅使用一颗 MCU，同时运行两路变频和一路 PFC。PFC 专用端子同时支持 Boost / Vienna 板型，运行时选用其中一种。LLC 暂停开发，控制板 LLC 接口取消。保留两路 A/B/Z、两路独立 SPI、两路制动、一路 TTL、CAN 和 SWD；无 USB、无霍尔。

结论：已完成 [引脚规划草案 A](pin_assignment.md)，实际 100 脚编号、GPIO、外设复用和 ADC 通道静态核对无物理冲突。可继续按两路 24 脚变频端子加一路 24 脚 PFC 专用端子设计；PFC 波形与同步、ADC 有效窗口和实时性能尚未验证，不能视为三套控制已具备同时运行能力。

## GPIO 预算

| 功能 | MCU 信号脚 |
|------|------------|
| 两路变频，保留三相电流 / 电压与 NTC | 32，每路 6 PWM + ENABLE / FAULT_N + 8 ADC |
| Vienna PFC | 15~18：3~6 PWM + 2 控制 + 9 ADC + 1 预充 |
| 两路 A/B/Z | 6 |
| 两路独立 SPI | 8 |
| TTL | 2 |
| CAN | 2 |
| SWDIO / SWCLK | 2，复位 1 脚与额外调试组保留 3 脚在下文另计 |
| 两路制动 | 2，仅控制输出 |
| 合计 | 69~72 |

草案 A 按六路 PFC 命令的上限计 72 根功能信号，另加四路可编程灯 4 脚、晶振 2 脚、MCU 复位 1 脚，共 79 脚。为保持正常 SWD，调试组额外三脚不分配业务功能；另将 REF/LDO12 两脚留作模拟测试，合计 84 只 GPIO 全部安排，没有自由通用 GPIO。REF/LDO12 的保留属于草案选择，并非固定电源脚。若 PFC 最终仅需三路命令，可释放三脚；LED 数量尚未冻结。此预算替代此前未计复位和调试组限制的 75~78 脚估计。

两路变频接口的第 12/24 脚均不接 MCU，不再把旧的完整通用口 18 信号脚预算用于专用变频口。BOARD_ID、CAN 待机、SPI 额外中断、制动额外反馈如需加入，须先重排。

## ADC 预算

两路变频各 8 路，共 16 路；Vienna 需要三相电流 3、三相输入电压 3、上下半母线电压 2、NTC 1，共 9 路。合计 25 路，相比手册最多 27 路外部 ADC 输入，数量上余 2 路。

草案 A 已分配 ADC0 / ADC1 / ADC2 各 9 / 7 / 9 路，并将每个控制级的三相电流分别放在三个 ADC 上。剩余 ADC1_CH8 与 ADC2_CH7 对应所保留的 LDO12 / REF 测试脚。通道数不等于吞吐或采样时序已满足：三套控制共享 ADC，须统筹有效窗口、序列、触发和模拟建立时间；电压采样频率也须满足相应控制环，NTC 可安排较低频率。

## PWM、编码器与定时器

官方用户手册 v1.98 第 14 章说明有五个通用 Timer，各可产生两路输出，并有四组编码器模块；编码器计数功能与 Timer 功能独立，但物理引脚仍可能冲突。

第 16 章说明两组 MCPWM 各有四对输出，每组通道 0/1/2 使用时基 0，通道 3 使用独立时基 1，并支持死区、采样触发与硬件急停。

- 两路三相变频分别使用 MCPWM0 / MCPWM1 的通道 0/1/2；两路 FAULT_N 分别落在各自 BKIN0。
- 两路制动分别使用 MCPWM0 / MCPWM1 的 CH3P、独立时基 1，保护与电机通道分组处理；模块时钟等公共设置不能随意重置。
- PFC 六路命令分配到 Timer0、Timer1、Timer4，各两路；不得用电机半桥互补关系直接套用 Vienna 双向开关。
- 两路编码器使用 QEP2 / QEP3，A/B/Z 均已有物理引脚。两路 SPI 使用 SPI0 / SPI1 和各自 GPIO 片选。
- PFC PWM 的物理引脚已落实，同步更新、采样触发及停止状态尚未验证，不把通用 PWM 视为与 MCPWM 等价。共同事件单周期启动可作为研究路线，不能直接当作连续同步已完成。
- PFC 功率板必须有独立于软件的硬件封锁路径。两路制动的独立故障保护和所属母线反馈策略也需落实。

## 算力与下一步验证

192 MHz 主频不能直接证明三套控制环同时满足时限。仍须确定变频控制算法、各级开关频率、电流环更新频率，以及编码器 SPI 读取频率，再评估最坏中断耗时与 DMA 调度。硬件 PWM 连续输出不要求每个边沿进入中断。

实际引脚表已完成，下一步验证 PFC 六路命令的同步/更新、三套控制的采样时序，以及上电/故障状态，再冻结最小系统和接口原理图。当前结论为“物理引脚静态核对通过，时序及实时性能待验证”。完整脚号见 [CSV](../hardware/LKS32MC451VCT8_pin_plan.csv)。
