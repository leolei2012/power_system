# OWNVERTER

- 仓库：https://github.com/owntech-foundation/OWNVERTER
- 文档（1.1.0）：https://docs.owntech.org/latest/ownverter/1.1.0/getting_started/
- 控制板：https://github.com/owntech-foundation/SPIN
- 许可：硬件 CERN-OHL-S，文档 CC BY-SA
- 工具：KiCad。有 Gerber 和 BOM。文档称仍是 alpha。

OwnTech 的可重编程三相功率变换器，双向，主要给电机控制用。控制在独立的 SPIN 板上，MCU 为 STM32G474RE，与功率侧电气隔离。

## 文档中的指标

以 1.1.0 入门文档为准。GitHub 简介写成高压侧 10~100 V、低压侧 12~72 V、每路约 13 A、1 kW、200 kHz，和下面这组数不完全相同。

| 项 | 值 |
|----|----|
| 功率 | 1.3 kW |
| 高压侧 | 12~100 V，单路 |
| 低压侧峰值电压 | 92 V |
| 低压侧有效值电压 | 65 V |
| 每相峰值电流 | 20 A（焊盘跳线可改到 50 A 量程） |
| 每相有效值电流 | 14.14 A |
| 开关频率 | 约 200 kHz |
| 死区 | 文档示例约 200 ns（20 kΩ 设定电阻） |
| 栅极驱动峰值电流 | 约 4 A |

电流采样是隔离霍尔（资料里出现 ACS723 一类器件），电压采样有隔离放大器（AMC1311）。传感器接口包括霍尔、增量编码器和正余弦编码器。通信有 CAN 和 RS-485。

滤波后的电压可以从 L1 Ext、L2 Ext、L3 Ext 接进来，文档写的测量范围是 0~100 V。采样点可以选在开关节点，也可以选在外接滤波器之后。

## 和本板的对照

母线 100 V、功率约 1 kW、三相、控制板分开，这几项和第一版最接近。65 V 有效值覆盖我们的 0~60 V。外接滤波后电压采样，正好是交流源模式需要的点。

不要按它的 200 kHz 和 200 ns 死区来做第一版。我们的规格是 20 kHz、1 µs。它的功率级和 SPIN 是配套的，不是一块只留排针的功率板。

可参考的部分：母线电压范围、隔离采样的摆法、滤波后电压接口、控制板与功率板分离。不要整板复制，许可是相同方式共享。
